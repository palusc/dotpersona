This folder is for **contributors writing a new persona**, not for using Persona.

If you just want to summon an expert, ignore this folder — run `/persona` in Claude Code.

`PERSONA.template.md` is the blank starting point for a new persona file, referenced by
[`CONTRIBUTING.md`](../CONTRIBUTING.md) and [`docs/creating-a-persona.md`](../docs/creating-a-persona.md).
The fastest way to use it is `/persona new`, which fills it in for you via a guided interview.
